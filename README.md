# Графический лаунчер для управления сервером Minecraft с поддержкой настройки параметров и тем оформления.

## Возможности
- Запуск, остановка и перезапуск сервера Minecraft
- Просмотр консоли сервера в реальном времени
- Отправка команд на сервер
- Настройка параметров сервера через удобный интерфейс
- Поддержка тем оформления (темная/светлая)
- Управление параметрами Java
- Мониторинг состояния сервера

## Требования
- Java 17 или новее
- Apache Maven 3.6.3 или новее
- Сервер Minecraft (будет загружен автоматически при первом запуске)

## Сборка и запуск

1. Соберите проект с помощью Maven:
   ```bash
   mvn clean package
   ```
   или используйте обертку Maven (Maven Wrapper):
   ```bash
   mvnw clean package
   ```

2. Собранный JAR с зависимостями будет находиться в папке `target/` с именем `mcserverlauncher-1.0.0-jar-with-dependencies.jar`.

3. Запустите приложение:
   ```bash
   java -jar target/mcserverlauncher-1.0.0-jar-with-dependencies.jar
   ```

## Создание нативного пакета (Windows .exe)

Для создания нативного исполняемого файла (.exe) используйте команду:

```bash
mvn clean javafx:jlink jpackage:jpackage
```

Собранный установщик будет находиться в папке `target/jpackage/`.

## Запуск
1. Запустите приложение:
   ```bash
   java -jar build/libs/minecraft-server-launcher-1.0.0-all.jar
   ```
2. При первом запуске выберите папку, в которой будет находиться сервер Minecraft.
3. Нажмите кнопку "Запуск", чтобы запустить сервер.

## Использование
- **Консоль**: Позволяет просматривать вывод сервера и отправлять команды.
- **Настройки**: Позволяет настроить параметры сервера, такие как имя, порт, сложность и т.д.
- **Игроки**: Отображает список подключенных игроков.
- **Настройки Java**: Позволяет настроить параметры JVM, такие как выделяемая память.

## Настройка

### Конфигурационный файл
При первом запуске приложения создается файл `config.yml` в корневой директории приложения. Вы можете отредактировать его вручную или через интерфейс приложения.

### Темы оформления
Приложение поддерживает темную и светлую темы. Выбрать тему можно в настройках приложения.


